# Portfólio — GitHub Pages

Template inicial de portfólio pessoal, feito com HTML e CSS.

## Personalização

1. Abra `index.html` e substitua `[Seu nome]` pelo seu nome.
2. Coloque sua foto em `assets/foto.jpg` (a imagem será exibida em formato circular).
3. Edite o texto da seção **Sobre mim**.
4. Edite os títulos, descrições, tecnologias e links dos dois projetos.
5. Se quiser, altere as cores no início de `style.css`, dentro de `:root`.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `portfolio`.
2. Envie todos os arquivos e pastas deste projeto para a raiz do repositório.
3. No repositório, acesse **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub exibirá o endereço do site na própria página de configurações.

Não é necessário instalar dependências ou usar um processo de build.
